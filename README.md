## Database Management & SQL

A collection of **MySQL and DBMS interview preparation notes** with practical SQL examples. The notes cover basic SQL queries, filtering, pattern matching, sorting, aggregate functions, subqueries, joins, `GROUP BY`, `WHERE`, and `HAVING`.

### Topics Covered

* Basic SQL expressions and functions
* `WHERE`, `BETWEEN`, `IN`, `NOT IN`, and `IS NULL`
* Pattern matching with `LIKE` and wildcards
* Sorting with `ORDER BY`
* Removing duplicates with `DISTINCT`
* Aggregate functions: `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`
* Subqueries
* `INNER JOIN` and related join queries
* `GROUP BY` and `HAVING`
* Difference between `WHERE` and `HAVING`
* Practical SQL interview questions and solutions
